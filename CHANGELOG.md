# Changelog

All notable changes to this project will be documented in this file.

## 0.1.0 - 2026-06-07

- Initial MVP.
- Added CSV parsing.
- Added console, JSON, and Markdown reporters.
- Added rules for blank cells, duplicate headers, column count mismatch, mixed spaces, invisible characters, duplicate rows, postal codes, phone numbers, amount columns, and duplicate keys.
- Added schema JSON support for key columns, required columns, and basic column types.
- Added GitHub Actions CI, issue templates, PR template, and maintenance documentation.
